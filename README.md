# Employee Management System

A terminal-based Employee Management System written in Python. This application allows users to manage a structured list of employees directly through a Command-Line Interface (CLI), supporting operations such as adding employee records, removing records by ID, and displaying all data or specific data.

---

## 🚀 Prerequisites

Before running this project, ensure you have the following installed on your machine:
* **Python 3.14** (Python 3.6 or higher is recommended)

To verify your Python installation, open your terminal and run:
```bash
python --version
```
## 🛠️ Setup & Installation

Follow these step-by-step instructions to set up and run the project locally on your machine.

### 1. Clone the Repository
Clone this public repository to your local machine using git:
```bash
git clone https://github.com{priyeshpatidar}/{priyesh_vit_bhopal}
```

### 2. Navigate to the Project Directory
Change your working directory to the root level of the cloned repository:
```bash
cd priyesh_vit_bhopal
```

### 3. Dependencies
This application is built entirely using standard Python built-in features and loops. **No external dependencies or third-party packages are required**, making installation steps like `pip install` unnecessary.

### How to Navigate the CLI Menu
Once running, the application presents a menu with the following numeric choices:
* **`1` - Add Data:** Prompts you for the total number of records, followed by the specific `ID`, `Name`, `Experience (years)`, and `Salary` for each employee.
* **`2` - Remove Data:** Prompts you for a specific employee `ID` to remove that record from the active list.
* **`3` - show one data:**Prompts you for a specific employee `ID` to show that record from the active list.
* **`4` - Show All Data:** Displays a printed breakdown of all recorded employee logs currently stored in the system.
